# فصلي — منصة الطالب (نموذج تصميمي)

منصة طالب عربية افتراضية من ست صفحات: رئيسية باختيار الصف، تسجيل دخول تجريبي يتذكره المتصفح، لوحة مواد الطالب، صفحة مادة بدروسها، صفحة درس بفيديو وملخص وعلامة إكمال، وصفحة اعتمادات.

> **تنبيه**: هذا نموذج تصميمي لأغراض العرض. كل الأسماء والدروس والدرجات محتوى توضيحي، ولا توجد حسابات أو خوادم أو مدفوعات حقيقية.

## التشغيل
1. فكّي الضغط مع الحفاظ على بنية المجلدات.
2. افتحي `index.html` في متصفح حديث — يعمل مباشرة بلا خادم ولا إنترنت.
3. جرّبي «دخول الطالب» بأي اسم وصف؛ يُحفَظ الحساب التجريبي في `localStorage` فقط.

## البنية
```
index.html        الرئيسية + الصفوف + المميزات
login.html        دخول الطالبة التجريبي (اسم + صف)
dashboard.html    مواد الطالبة ونسب التقدم
class.html        دروس المادة
lesson.html       صفحة الدرس: فيديو + ملخص + إكمال
credits.html      الاعتمادات
assets/css/       التصميم (وضع ليلي/نهاري)
assets/js/        data.js (الصفوف والدروس)، i18n.js (عربي/إنجليزي)، app.js (المنطق)
assets/fonts/     El Messiri + Tajawal (woff2 محلية) + OFL.txt
assets/img/       رسوم مولّدة بالذكاء الاصطناعي
assets/video/     فيديو توضيحي قصير
```

## التخصيص
- الصفوف والمواد والدروس: `assets/js/data.js`
- كل العبارات العربية/الإنجليزية: `assets/js/i18n.js`
- الألوان: متغيرات `:root` و`[data-theme=dark]` أعلى `assets/css/style.css`

## الاعتمادات
انظري `credits.html` داخل المنصة. الخطوط بموجب رخصة SIL OFL 1.1، والصور والفيديو محتوى مولّد للعرض لا يمثل أشخاصًا أو مواد حقيقية.
