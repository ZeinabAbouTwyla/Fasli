# فصلي — منصة الطالب (نموذج تصميمي)

منصة طالب عربية افتراضية من ست صفحات: رئيسية باختيار الصف، صفحة صف تعرض مواده، صفحة مادة بدروسها المرتبة تتابعيًا، صفحة درس بفيديو وملخص وتتبع مشاهدة فعلي، تسجيل دخول تجريبي، ولوحة مواد الطالب مع بطاقة «واصل التعلم».

> **تنبيه**: هذا نموذج تصميمي لأغراض العرض. كل الأسماء والدروس والدرجات محتوى توضيحي، ولا توجد حسابات أو خوادم أو مدفوعات حقيقية.

## التشغيل
1. فكّي الضغط مع الحفاظ على بنية المجلدات.
2. افتحي `index.html` في متصفح حديث — يعمل مباشرة بلا خادم ولا إنترنت.
3. جرّبي «دخول الطالب» بأي اسم وصف؛ يُحفَظ الحساب التجريبي في `localStorage` فقط على نفس الجهاز.

## مسار التعلم
- من الرئيسية: اختيار الصف يفتح مواد الصف، والمادة تفتح دروسها بالترتيب.
- كل درس فيه فيديو (مقطع توضيحي قصير في النموذج) وملخص نقاط.
- نسبة المشاهدة تُقاس من وقت تشغيل الفيديو الفعلي، والدرس يكتمل تلقائيًا عند 90٪.
- الدرس التالي في المادة يفتح فقط بعد اكتمال الدرس الحالي.
- التقدم يُحفَظ في متصفح الطالب على نفس الجهاز (لا مزامنة بين الأجهزة في النموذج).

## البنية
```
index.html        الرئيسية + الصفوف + المميزات
class.html        صف → مواده، ثم مادة → دروسها (حسب المعاملات)
lesson.html       صفحة الدرس: فيديو + ملخص + نسبة مشاهدة + فتح التالي
login.html        دخول الطالب التجريبي (اسم + صف)
dashboard.html    مواد الطالب ونسب التقدم وبطاقة المتابعة
credits.html      الاعتمادات
assets/css/       التصميم (وضع ليلي/نهاري)
assets/js/        data.js (الصفوف والدروس)، i18n.js (عربي/إنجليزي)، app.js (المنطق)
assets/fonts/     El Messiri + Tajawal (woff2 محلية) + OFL.txt
assets/img/       رسوم توضيحية
assets/video/     مقطع توضيحي قصير
```

## التخصيص
- الصفوف والمواد والدروس: `assets/js/data.js` — استبدلي `DEMO_VIDEO` بروابط فيديو الدروس الحقيقية عند توفرها.
- كل العبارات العربية/الإنجليزية: `assets/js/i18n.js`
- الألوان: متغيرات `:root` و`[data-theme=dark]` أعلى `assets/css/style.css`

## الاعتمادات
انظري `credits.html` داخل المنصة. الخطوط بموجب رخصة SIL OFL 1.1، والمحتوى كله توضيحي للعرض.
